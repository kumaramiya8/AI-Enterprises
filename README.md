# AI Enterprises - Turnkey HVAC Engineering & Contracting Website

🌐 **Live Demo:** [https://kumaramiya8.github.io/AI-Enterprises/](https://kumaramiya8.github.io/AI-Enterprises/)

Modern, responsive, mobile-optimized website built for **AI Enterprises**, an engineering and contracting company specializing in turnkey Heating, Ventilation, and Air Conditioning (HVAC) systems.

---

## ❄️ Company Profile & Scope
**AI Enterprises** provides end-to-end HVAC solutions:
- **Design & Heat Load Modeling:** Computerized ASHRAE/ISHRAE compliant thermal analysis, 3D BIM coordination, and duct routing.
- **Equipment Supply:** OEM-direct commercial chillers, VRV/VRF systems, package units, and AHUs/FCUs from Daikin, Voltas, Blue Star, Carrier, Trane, and York.
- **Precision Installation:** SMACNA-standard GI & pre-insulated duct fabrication, high-pressure nitrogen hold testing (550 PSI), and cleanroom laminar ceilings.
- **Testing, Adjusting & Balancing (TAB):** Calibrated digital CFM flow balancing, hydronic water balancing, and acoustic vibration signoffs.
- **Maintenance & 24/7 Breakdown:** Comprehensive AMC support with emergency mobile service vans across North India.

### Sectors Catered:
1. **Commercial Buildings & High-Rises**
2. **Banquet Halls & Convention Centers**
3. **Hotels & Luxury Hospitality**
4. **Corporate Offices & IT Hubs**
5. **Hospitals & Healthcare Cleanrooms (OTs)**
6. **Retail Showrooms & Shopping Malls**
7. **Industrial Facilities & Warehouses**

## 🚀 Key Features

- **Company SVG Logo Integration:** High-resolution integration of the official logo in the floating navigation bar, mobile panel, favicon, and footer.
- **Modern Design System Standards:**
  - Built to strict visual and copywriting rules (`landing-page-design` skill).
  - Single typeface (**Manrope**), flat dark palette (`#000000`, `#181818`, `#1F1F1F`, `#272727`, `#313131`), zero background gradient blobs.
  - Sentence case headings, no hyphens inside text copy, and balanced text line-wrapping (`text-wrap: balance` / `text-wrap: pretty`).
  - Mandatory Tagline Reveal section with word-by-word scroll transition on `cubic-bezier(0.22, 1, 0.36, 1)`.
- **Animated Lucide Icons:**
  - Official `lucide` icon integration with micro-interactions across CTAs, cards, metrics, and accordions.
  - Hover arrow shifts, phone shake, card icon elevation, and ambient cooling fan rotation.
  - Respects `prefers-reduced-motion`.
- **Interactive HVAC Capacity & Load Estimator:**
  - Real-time client calculator based on facility type, square footage, ceiling height, roof sun exposure, and occupancy density.
  - Automatically calculates estimated Cooling Tonnage (TR), Airflow (CFM), and recommends tailored system topologies (e.g. VRV/VRF vs. Chilled Water).
  - One-click **"Apply this estimate to project inquiry"** button that transfers calculated values directly into the consultation form.
- **Full Content Tabs & Sections:**
  - **Services:** Filterable tabs across core HVAC disciplines.
  - **Sectors:** Detailed breakdown of challenges and engineered solutions for all 7 primary industries.
  - **Projects / Works Showcase:** Verified installations with equipment and status specifications.
  - **OEM Partners:** Marquee of Tier-1 brands (Daikin, Voltas, Blue Star, Carrier, Trane, York).
  - **Offices Directory:** Greater Noida Head Office, Lucknow Regional Office, Ayodhya/Faizabad Division, and Gurugram Operations.
- **Mobile Experience & Ergonomics:**
  - Floating compact navigation bar with full-height mobile panel and stepped link transitions.
  - Large touch targets (48px+), fluid typography, and zero horizontal overflow (tested at 390px).

## 🛠️ Development & Deployment

### Run Development Server
```bash
npm install
npm run dev
```
Local URL: `http://localhost:5173`

### Production Build
```bash
npm run build
```
Creates production-ready static assets in `/dist`.

### Production Preview
```bash
npm run preview
```
Previews the compiled production build locally.
